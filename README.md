🇬🇧 English

JOJOS PWA is a web-based store management application that I developed.
It is built with Flutter and works as a Progressive Web App.
The system includes inventory management, sales management, and sales history tracking.
Role-based access control is implemented (Admin, Warehouse, Cashier).
Data is stored and updated in real time.
The architecture is designed with maintenance and scalability in mind.
The UI is clean and user-friendly.
The main goal is to improve business efficiency and data visibility.
The project simulates a real business environment.
I continue to improve and optimize the system.
